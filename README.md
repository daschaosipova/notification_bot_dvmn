# Telegram-бот уведомлений о проверках на Devman

Скрипт отслеживает статус проверки ваших домашних заданий на сайте [Devman](https://dvmn.org) с помощью механизма Long Polling и отправляет уведомления в Telegram, как только преподаватель проверит работу.

## Как установить

Для работы скрипта вам понадобится Python версии 3.7 или выше.

1. Скачайте код к себе на компьютер.
2. Установите необходимые зависимости из файла `requirements.txt`:

```bash
pip install -r requirements.txt
```

## Настройка окружения

Для работы бота требуются токены авторизации и идентификатор чата. Создайте в корневом каталоге проекта файл `.env` и добавьте в него следующие переменные:

```env
DVMN_TOKEN=ваш_токен_api_devman
TELEGRAM_TOKEN=токен_вашего_телеграм_бота
TG_CHAT_ID=ваш_идентификатор_чата_в_telegram
```

* **DVMN_TOKEN** — персональный токен, который можно получить в [личном кабинете Devman на странице API](https://dvmn.org/api/docs/).
* **TELEGRAM_TOKEN** — токен вашего бота, созданного через [@BotFather](https://t.me).
* **TG_CHAT_ID** — ваш уникальный ID пользователя в Telegram. Узнать его можно, например, у бота [@userinfobot](https://t.me).

## Запуск

Запустите скрипт стандартным способом — ID чата возьмется из файла `.env`:

```bash
python main.py
```

При запуске скрипт начнет выводить логи в консоль в следующем формате:
```text
2026-10-19 08:29:05 [INFO] root: bot started
2026-10-19 08:32:04 [INFO] root: found new review
```

## Запуск на сервере (Systemd)

Проект настроен для непрерывной фоновой работы на удаленном сервере в виде системной службы `systemd`. 

Управление демоном осуществляется стандартными командами:
* Перезапуск службы: `systemctl restart dvmn-bot.service`
* Просмотр логов в реальном времени: `journalctl -f -u dvmn-bot.service`
